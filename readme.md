Instalation With Vanila Ubuntu / Linux
```bash
apt-get update
apt-get install sudo
sudo apt install git
sudo apt install npm
npm install -g typescript
npm install -g ts-node
```

how to run program by sh script
```bash
1. npm install
2. run bash script command: sh /bin/parking_lot.sh  
3. run bash script unit testing command: sh /bin/run_functional_tests.sh
4. run bash script setup depedencies and build: sh ./bin/setup.sh
```


how to run program by build
```bash
1. npm install
2. npm run build
3. run command: node ./build/index.js  
```

how to run program without build
```bash
1. npm install
2. npm run start
```
