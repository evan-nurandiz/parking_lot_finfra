## Installation
Test Parking Lot

node version
```bash
16.14.0
```

Instalation With Vanila Ubuntu / Linux
```bash
apt-get update
apt-get install sudo
sudo apt install git
sudo apt install npm
npm install -g typescript
npm install -g ts-node
```

how to run program by cmd
```bash
1. npm install
2. run bash script command: /bin/parking_lot.sh  
3. run bash script unit testing command: /bin/run_functional_tests.sh
```


how to run program by build
```bash
1. npm run build
2. run command node ./build/index.js  
```
